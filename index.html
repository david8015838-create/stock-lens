App Guide

📈 資產管理

● 新增部位： 點擊 Portfolio 區塊的 Add Position 按鈕，輸入代號。（注意：此功能僅用於快速建立初始持股，不會產生交易紀錄）

● 買入/賣出： 使用 Buy 或 Sell 記錄交易，系統會自動計算平均成本。（交易紀錄可點擊列表中的資產名稱查看）

● 即時更新： 點擊 Sync 獲取最新市場價格 (Yahoo Finance)。

📊 數據分析

● 隱私模式： 點擊右上角 👁️ 眼睛圖示 隱藏/顯示敏感金額數據。

● 目標配比： 在列表最左側 Target % 欄位輸入您理想的資產占比。

● 缺口分析： 下方圖表會顯示當前配比與目標的差距，協助您進行再平衡。

💡 進階功能

● 現金倉位： 點擊 Cash Position 區塊調整您的閒置資金。

● 槓桿與質押： 編輯資產時可勾選「槓桿」或設定「質押股數」，精確追蹤資產狀況。

● 複利試算： 點擊頂部 計算機圖示 規劃長期投資目標。

💾 數據管理 (遷移必用)

※ 若更換網址或設備，請先匯出數據，再於新網址匯入。
